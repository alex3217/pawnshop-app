# Dealer Dispute and Return Policy Draft

Status: operational and legal review required; not customer terms.

A buying shop may report wrong/missing items, material condition mismatch, quantity or serial mismatch, counterfeit concern, shipping damage, or incomplete lots before the displayed inspection deadline. Opening a qualifying dispute pauses seller release. Evidence should reuse existing uploads and transaction events.

Return states should progress through requested, evidence review, seller response, authorized, tracked in transit, received/inspected, and refund decision. A pending return blocks release. If a transfer already occurred, any refund or transfer-reversal path requires finance authorization, idempotency, reconciliation and audit logging.

PawnLoop provides transaction workflow tooling and Protected Dealer Payment controls; it is not described as an escrow provider. Final deadlines, evidence standards, loss allocation, authentication, shipping insurance, prohibited inventory, arbitration and jurisdiction terms require counsel and Stripe review before activation.
